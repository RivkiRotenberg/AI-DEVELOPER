# 🌦️ Israel Weather MCP Server

פרויקט זה מממש שרת MCP (Model Context Protocol) המאפשר לשלוף נתוני מזג אוויר עדכניים מישראל באמצעות אוטומציה של דפדפן.

## 🎯 המטרה
השרת ניגש באופן אוטומטי לאתר מזג אוויר ישראלי, מבצע חיפוש עיר ושולף את המידע עבור המשתמש.

## 🛠️ טכנולוגיות
- **MCP SDK**: הפרוטוקול לחיבור כלים ל-LLM.
- **Playwright**: ספריית אוטומציה לשליטה בדפדפן (Chromium).
- **Python**: שפת הפיתוח.
